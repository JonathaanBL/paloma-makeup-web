# Paloma, maquillaje profesional

Página web de Paloma, maquilladora chilena en Nueva York: novias, maquillaje social, alisados y clases de automaquillaje.

Es un sitio estático (HTML, CSS y JavaScript, sin compilación). El labial 3D usa Three.js desde jsDelivr.

- `index.html`: versión principal, en negro.
- `rosa/`: primera versión, en rosa y berenjena.
- `img/`: fotos de su Instagram [@paloma.makeupprofesional](https://www.instagram.com/paloma.makeupprofesional/).

## Verla en local

```bash
python -m http.server 5180
```

Luego abre http://localhost:5180.

## Antes de publicar

Los precios, horarios, zonas de atención y textos sobre su forma de trabajar son de ejemplo: hay que confirmarlos con Paloma. La foto de Brooklyn es de Danny Lyon (1974, dominio público, vía Wikimedia Commons).
